# 台灣勞基新聞海報素材

此資料夾存放可公開讀取的原始新聞海報圖片，供新聞網站與 Metricool Facebook 排程使用。

## 命名

`YYYY-MM-DD-topic.png`，例如 `2026-11-17-workplace-bullying.png`。

## 公開圖片網址

`https://raw.githubusercontent.com/sam0989422478/taiwan-labor-news/main/assets/YYYY-MM-DD-topic.png`

圖片必須實際上傳至儲存庫，且可透過上述網址直接讀取原始 PNG/JPEG，才可以交給 Metricool `media` 欄位。不可使用 Canva 縮圖、GitHub HTML 頁面或聊天室內部檔案網址。

## 發布驗證

1. 驗證新聞日期、法規與貼文內容。
2. 確認原始廖茂霖照片及原版公司 Logo。
3. 確認公開圖片網址能讀取完整圖片。
4. 透過 Metricool 排程或發布 Facebook 圖文。
5. 核對已發布狀態及 Facebook 貼文連結；未成功不得計入每月20篇。

目前 GitHub 文字檔寫入權限已測試成功；聊天連接器的 `create_file` 僅接受 UTF-8 文字，尚不具備直接上傳 PNG/JPEG 二進位檔案的功能。
